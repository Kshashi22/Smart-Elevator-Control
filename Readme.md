# Smart Elevator Control System - ER Diagram

## Project Overview

This repository contains the **Entity-Relationship (ER) Diagram** for the **Smart Elevator Control Platform** developed by LiftGrid Systems.

The system is designed to manage intelligent elevator operations in large commercial buildings, malls, airports, hospitals, and high-rise residential complexes across India. It efficiently handles multiple buildings, multiple elevators per building, floor requests, ride assignments, maintenance tracking, and ride history logging.

## Key Features Modeled

- Multi-building support
- Floors and elevators per building
- Many-to-many relationship between elevators and floors (ElevatorFloor junction)
- Real-time ride requests from floors
- Smart ride assignment to suitable elevators
- Complete ride logging for analytics
- Elevator status monitoring
- Comprehensive maintenance history tracking
- Separation of static configuration and dynamic operational data

## ER Diagram

![Smart Elevator Control System ER Diagram](diagram.png)


### Core Entities:
- **Building** – Represents each connected building
- **Floor** – Individual floors within a building
- **Elevator** – Elevator configuration and current status
- **ElevatorFloor** – Junction table for many-to-many relationship (which elevator serves which floors)
- **RideRequest** – Requests generated by users from floors
- **RideAssignment** – Assignment of a request to a specific elevator
- **RideLog** – Historical ride/trip records for analytics
- **MaintenanceRecord** – Maintenance history per elevator

### Important Relationships:
- One Building has many Floors and many Elevators
- One Elevator can serve multiple Floors (and vice versa)
- One RideRequest can be assigned to one Elevator via RideAssignment
- Each ride generates a detailed RideLog entry
- Maintenance records are tracked separately for each elevator
